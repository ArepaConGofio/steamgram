# Casos de uso

El ciclo de vida de la aplicación y su funcionamiento principal gira en torno al flujo que emplean otras aplicaciones/redes sociales populares como Instagram. Hay presente una autenticación con nombre de usuario y contraseña requerida, una pantalla de comunidad donde el usuario podrá ver las últimas publicaciones relacionadas con sus juegos favoritos, un buscador donde el usuario podrá mirar (e importar directamente los datos de la API de IGDB a nuestra app) los detalles de un videojuego, y otra que hace de biblioteca con todos los juegos que el usuario tenga guardados, para tener un fácil acceso a sus detalles, publicaciones y *reviews*.
