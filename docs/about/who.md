# ¿Quienes somos?

El nombre de **ArepaConGofio** nace de la combinación de dos elementos claves, característicos, de nuestra identidad cultural. Estudiantes del ciclo formativo de desarrollo de aplicaciones multiplataforma, **[Alejandro Salazar](https://github.com/strSalazar)**, programador canario, destaca con su habilidad como desarrollador *back-end* para fundar los cimientos de las aplicaciones: la capa lógica y el manejo de datos seguro y eficiente. Por otro lado, **[Jesús Lugo](https://jesuslugo2002.github.io/)**, programador venezolano, aporta su esfuerzo en entregar interfaces amigables, usables y accesibles como desarrollador *front-end*, intentando pintar con fuerza la identidad de esta marca empresarial en los productos que desarrollan.

Esta vez ofrecen juntos un producto especial para ambos por un gusto compartido: el desarrollo de videojuegos, que tras observar el contexto local y analizar las oportunidades y amenazas, presentan este producto con la esperanza de aportar un grano de arena.
