# Desarrollo del proyecto

## Recursos utilizados

### Control de versiones

- **[Github](https://github.com/)**: De los sistemas de control de versiones más populares, además de sus herramientas para proyectos como el sistema Kanban o la gestión de *issues* para determinar las tareas pendientes.

### IDE

- **[Visual Studio Code](https://code.visualstudio.com/)**: Gracias a su flexible sistema de perfiles y su amplio catálogo de extensiones, este IDE nos ha ayudado a realizar un trabajo fluido aún cambiando de contexto constantemente.

### Diagramación

- **[Draw.io](https://www.drawio.com/)**: Herramienta de diagramación utilizada para la creación de los diagramas de caso de uso y de entidad-relación.

### Diseño

- **[Figma](https://www.figma.com/)**: Herramienta de diseño gráfico y prototipado de interfaces para la creación colaborativa del *front-end*.
- **[Dribble](https://dribbble.com/)**: Una red social para que los diseñadores puedan autopromocionar su trabajo, sirviendo como un repositorio de portafolios, encontrar u ofrecer trabajo y encontrar inspiración para el diseño web o de aplicaciones.
- **[Android Design Guidelines](https://developer.android.com/design?hl=es-419)**: Guias de diseño proporcionadas por Android para lograr una mayor accesibilidad y usabilidad en dispositivos Android.
- **[Material 3 Guidelines](https://m3.material.io/)**: Guias de diseño y experiencia de usuario proporcionadas por Google. Un producto *Open Source* que va muy de la mano con Figma.
- **[Web Content Accessibility Guidelines (WCAG) 2.1](https://www.w3.org/TR/WCAG21/)**: Un amplio documento donde se detallan una gran variedad de recomendaciones y estándares de accesibilidad.
- **[Adobe Color](https://color.adobe.com/es/)**: Una herramienta de Adobe que nos proporciona la posibilidad de explorar y diseñar paletas de colores.

### Documentación

- **[Zensical](https://zensical.org/)**: Generador de documentación y sitios web estáticos, utilizado para crear la documentación técnica del proyecto y publicarlo en Github Pages.

### Testing y mejora de la aplicación

- **[Sonarqube](https://docs.sonarsource.com/sonarqube-community-build)**: Herramienta de analisis y mejora de calidad de código utilizado tanto en el *back-end* como en el *front-end*.
- **[Expo Go](https://expo.dev/go)**: Una herramienta que permite construir, *debuggear* y probar la aplicación en el dispositivo movil. Fue implementado y proporcionado por React Native y Expo.
